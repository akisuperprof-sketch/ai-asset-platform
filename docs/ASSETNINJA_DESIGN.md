# ASSETNINJA_DESIGN.md (AssetNinja Design OS Constitution)

## 1. Brand Philosophy
AssetNinja は「AI素材サイト」ではなく、「プロのクリエイターが安心して業務で使える、日本発のプレミアム透過素材OS」である。

- **忍者OS思想**: 主役はあくまで「ユーザーが作る作品」。UIは忍者のように気配を消し、静かで機能的でなければならない。
- **静かな高級感**: 派手なエフェクトで誤魔化さない。余白とタイポグラフィで品質を表現する。
- **日本的ミニマル**: 禅的で無駄のない洗練。情報過多を避け、研ぎ澄まされたUI。
- **プロ向け・道具感**: プロフェッショナルが使う「高品質なツール（道具）」としての信頼感。
- **AIを前面に出さない**: 「AIで作った」こと自体は売りではない。結果として得られる「素材のクオリティの高さ」だけを価値として提供する。

## 2. Visual Language
- **Dark Premium**: ベースは漆黒に近いダークトーン。重厚感と画面への没入感を高める。
- **Japanese Cyber Minimal**: ネオンサインのような下品なサイバー感ではなく、マットで精緻な最新機器のような和風サイバー。
- **Transparent Layer UI**: 透過素材を扱うプラットフォームとして、UI自体にも繊細な「Glass (透過)」レイヤーを活用する。
- **Living OS**: 単なる静的ページではなく、息づくような滑らかな質感を持たせる。

**【禁止事項】**
- ゲーミング感のある原色ネオン
- 安いSF感や子供っぽい未来感
- 「AI generated」を強調する安っぽいバッジや過剰な演出

## 3. Typography Rules
- **フォントファミリー**: `Noto Sans JP`, `Inter` (数字・欧文)
- **文字間 (Letter Spacing)**: 見出しは `-0.02em`〜`-0.04em` で引き締め、本文は `0.02em`〜`0.05em` で可読性を担保。
- **行間 (Line Height)**: 本文 `1.6`〜`1.8`、見出し `1.2`〜`1.4`。
- **英語比率**: メニューや装飾には適度に英語を配し、グローバルでプロフェッショナルな印象を与える。
- **見出し重量**: `font-medium` (500) または `font-semibold` (600)。

**【禁止事項】**
- `font-bold` (700以上) の無意味な乱用
- 本文と見出しの極端すぎるサイズ差

## 4. Spacing Rules
余白は厳密にトークン化し、AIによる勝手な変更を禁ずる。

- **Section Spacing (Desktop)**: `120px` (`py-32`)
- **Section Spacing (Mobile)**: `64px` (`py-16`)
- **Card Spacing (Grid Gap)**: Desktop `24px` (`gap-6`), Mobile `16px` (`gap-4`)
- **Mobile Padding**: 左右 `16px` (`px-4`) 固定
- **Desktop Density**: 最大幅 `1280px` (`max-w-7xl`)

## 5. Color Token System
- **Background**: `bg-zinc-950` (#09090b) - 完全な漆黒ではなく、極めて暗いジンク。
- **Surface**: `bg-zinc-900` (#18181b) - カード等の基本背景。
- **Border**: `border-white/10` - 繊細で主張しない線。
- **Primary Text**: `text-white` または `text-zinc-100`。
- **Secondary Text**: `text-zinc-400`。
- **Accent**: 微細なシルバー (#e4e4e7) または、極めて彩度を抑えたブランドカラー（薄いブルーグレーなど）。
- **Glass**: `bg-zinc-900/50 backdrop-blur-md`。

**【禁止事項】**
- 高彩度（原色の赤、青、緑など）の乱発
- ギラギラしたグラデーションや原色ネオンの光

## 6. Motion Philosophy
- **忍者のように静か**: スムーズだが過剰にアピールしない。
- **速いが派手ではない**: `duration-200`〜`duration-300` でキビキビ動く。
- **煙のように消える**: フェードとわずかなスケール（`scale-95` 等）を活用。
- **重力感・思考が流れる感じ**: イージングは `ease-out` を基本とする。

**【禁止事項】**
- bounce などのコミカルな動き
- 激しい回転、極端なスケールアップ
- TikTok風の派手で目障りな演出

## 7. Card Design Rules
- **Radius**: `rounded-xl` または `rounded-2xl`（シャープさと柔らかさのバランス）。
- **Border & Glass**: `border border-white/5` に微細な `bg-white/[0.02]` を重ねる。
- **Hover**: 浮き上がるのではなく、光がうっすら当たる（`bg-white/[0.05]`）か、枠線が微かに光る（`border-white/20`）。
- **Preview Size / Ratio**: 正方形 (`aspect-square`)。
- **Metadata Density**: タイトルとタグのみ。余計なアイコンや装飾を排除し、コンテンツ（素材）を主役にする。

## 8. Transparency Preview Rules
透過PNGの品質をプロが確認するためのプレビュー機能。
- **背景切り替え**: GRID (市松模様) / LIGHT / DARK / PS風 (Photoshop風チェッカー)。
- **視認性**: 白背景（LIGHT）にした際、オブジェクトの白フチが浮かないことを厳密に検証可能なコントラスト。
- **境界線**: 素材そのものには border や shadow をかけず、ピクセルレベルの品質をそのまま見せる。

## 9. Commercial Quality Rules (生成・QA基準)
Adobe Stock, Envato, Freepik 基準の商用利用可能品質。
- **素材用途成立**: 単体でデザインに組み込めるか。
- **被写体明確**: 何の画像か一瞬で判別できるか。
- **切り抜き品質**: 輪郭のエッジがシャープで、背景の残りや白フチが一切ないこと。
- **Canva利用適性**: ユーザーがそのままCanva等にアップロードして合成した際、違和感がないこと。

## 10. SEO / AEO Tone
- **トーン＆マナー**: 「プロ向けの確かなツール」。丁寧で知的、しかし専門的すぎない。
- **必須キーワード群**: 商用利用可能, 無料透過PNG, 高品質, 日本発
- **【禁止事項】**: 「AI generated」「AI art」「experimental (実験的)」などの言葉。AIはあくまで裏方の技術であり、出力物の価値を下げる言い訳に使わない。

## 11. D作戦 Rules (自律量産時の掟)
1. 量産してもブランド崩壊しない（品質＞量）。
2. 少しでも怪しい低品質画像は「即 reject」。
3. 世界観の維持（一貫したライティングとテクスチャ）。
4. 1000枚、1万枚生成しても、手作業で作られたような統一感を保つ。

## 12. Do Not Rules (絶対禁止事項まとめ)
- AIっぽいUIデザイン（キラキラした魔法の杖アイコンなど）
- 低品質で安っぽいネオンや光彩
- 雑なグロー効果（Box shadowの乱用）
- 抽象的な図形素材の通過
- 意味不明な低品質背景・グラデーション
- 情報がごちゃごちゃしたレイアウト
- 「未来感」のやりすぎ（サイバーパンク化）
- ゲーミングPCのようなUI
- 無意味で安っぽいアニメーション（画面全体が揺れる等）
